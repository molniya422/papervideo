# Model Asset Brief（强制建模描述网关）

**一句话**：先写清楚"这到底是一件什么东西"，才允许动手做。
建模的精度问题 90% 源于描述缺失——"一只狗"三个字开拼几何体，出来的必然是灰模拼接感。

## 触发条件（全部强制，无一豁免）

| 建模路径 | 也必须先有 brief | 理由 |
|---|---|---|
| Blender 脚本建模 | ✅ | 脚本逐字段翻译 brief；没有 brief 的脚本是瞎拼 |
| AI 生成（Rodin/Meshy 等） | ✅ | 提示词 = brief 第 2 字段原文，禁现场编 |
| CC0/外部模型下载选型 | ✅ | brief 的来源策略 + 验收清单决定选哪个、够不够格 |
| lib3d 程序化函数 | ✅ | 修 lib3d 模型函数 = 改 brief → 改代码 |

## 产出契约：`3-figures/asset_briefs/<asset>.md`（一资产一份，12 项缺一不可）

文件名 = 资产名小写（`dog.md` / `person.md` / `car.md`）。执行器谓词按 12 个小节标题校验。

### 1. 一句话身份
品种/类别级描述，禁笼统名词。
- ❌「一只狗」 ✅「成年拉布拉多，站姿侧面朝前，短毛、体格壮实、表情温和」

### 2. AI 生成提示词（AI 路径必填；程序化路径填写供"心象"校准）
结构化句：`主体 + 风格 + 材质/纹理 + 姿态/尺度`，15-40 词，英文原句 + 中文对照。
单主体单风格；几何须任意角度可描述（禁"正面看是 X"这类单角度描述）。
示例：`A standing adult Labrador retriever, stylized game-asset style, smooth short
tan fur with subtle darker back, neutral pose facing forward, clean silhouette, 1.2m tall`

### 3. 三视图 turnaround（文字版 model sheet）
- **正视图**（从它面朝的方向看）：3-5 句，宽/肩/头宽关系
- **侧视图**：3-5 句，背线走向、胸深、腹线、腿的夹角
- **背视图**：2-3 句，臀宽、尾根位置
每句尽量含比例断言（"肩高约为体长的 55%"）。

### 4. 比例数值表
肩高 / 体长 / 头长 / 腿长等关键量：**数值 + 单位**，给出边界盒目标（W×H×D）。
在场景中的目标尺度（占画面比例、与网格单元的倍数关系）。

### 5. 材质与表面（逐部位）
每个部位写：表面类型（短毛/长毛/皮肤/金属/玻璃/布）+ 粗糙度/金属度/清漆 + 纹理计划
（纯色 / 程序纹理 / 贴图来源与许可证）。**禁"默认灰模"**——每个部位有表面答案。

### 6. 色彩表（十六进制，逐部位）
主体色 / 次要色 / 眼鼻爪等点缀色，全部 `#RRGGBB`；必须对齐全片色板
（design-intake 的色板 + 荧光绿唯一高亮纪律），冲突时让色。

### 7. 朝向与坐标
forward 轴（GLB 约定 +Z）、up 轴、原点落点（脚底/几何中心）、导入 scale、
与场景对象（网格单元/车辆）的相对尺度。

### 8. 结构细节清单（≥4 处，对应建模精度四项③）
"轮拱挖孔/分体玻璃座舱/辐条车轮"级别的**可指认细节**，逐条列出。
四项自检：①环境反射 ②真接触阴影 ③结构细节 ≥4 处 ④透光件非裸盒。

### 9. 来源策略（主选 + 备选链 + 许可证）
程序化 / AI 生成 / CC0 下载——选择理由；下载必须记录许可证（CC0/CC-BY 及署名要求）；
备选链（主选失败走哪条）。灰模/拼接感高风险路径要写缓解手段。

### 10. 拒绝项（明确不要）
逐条写：灰模、椭球拼接感、悬浮件、剪影含糊、比例失真、多余配饰……

### 11. 验收清单（导演过 brief 的判定条目）
- 剪影三问：正/侧/背任意一张纯剪影，能否一眼认出"是什么"？
- 材质问：闭上眼能想象出表面吗（毛的走向/金属的反光）？
- 拼接问：任何视角有没有"两块几何体相加"的痕迹？
- 色板问：每个颜色是否在片内色板纪律内？
- 尺度问：放进场景（网格/车/人旁边）比例是否可信？

### 12. 复用计划
哪些章节复用此资产、需要什么变体（换色/换姿态/换尺度）、是否需要动画绑定。

## 流程纪律

1. **brief 先行**：先落 `3-figures/asset_briefs/<asset>.md` → 导演过 brief → 才许建模。
2. **翻译不失真**：建模脚本/AI 提示词逐字段翻译 brief；实现物与 brief 冲突 = 返工，改实现不改 brief（除非导演改 brief）。
3. **一资产一 brief**：狗/人/车各一份；变体在"复用计划"里声明，不另开 brief。
4. **brief 也是验收基准**：小样帧对着 brief 逐条打勾，"看着还行"不是验收。

## Misuse（禁止）
- 未写 brief 直接建模（任何路径）
- 「一只狗」级别的笼统身份描述
- 材质栏留空 / "默认材质"
- 下载无许可证记录的模型
- brief 与建模实现长期脱节（改实现不改 brief）

## Alt
无——强制网关（与 motion-doctrine 同地位：动效前先读法则，建模前先写 brief）。
