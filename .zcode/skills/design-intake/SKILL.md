# Design Intake · 设计需求访谈

写 brief 之前先问清楚。**问得具体，后面少返工**：不问"你想要什么风格"，
而是给四种能一眼看懂的风格卡片，让对方选。

## 何时用

- 用户说"做个视频"但没说风格、时长、画幅、配音；
- 同一主题要重做（必须先确认这次要换什么、保留什么）；
- 用户主动说"先问我要什么风格"。

**不要**问已有答案的问题（论文、受众、语言在上一步已确认）。

## 提问方式

用 `AskUserQuestion`，**每轮 4 题**，最多两轮；每题 2–4 个具体选项，
第一项放推荐值并标 "(Recommended)"。用户选 "Other" 时按自由文本记录。

### 第一轮 · 视觉基座

| 问题 | 选项（每项都要能想象出画面） |
|---|---|
| 视觉语言 | ①工程蓝图（深蓝方格纸 + 线框 + 尺寸标注）②编辑纸本（暖白 + 衬线 + 细分割线）③暗场霓虹（近黑 + 高饱和发光）④极简白（大量留白 + 单一强调色） |
| 主强调色 | ①冷蓝 ②暖橙 ③薄荷绿 ④品红 |
| 排版气质 | ①紧凑技术感（等宽标注 + 大标题）②杂志编辑感（衬线 + 大留白）③粗野主义（超粗字 + 硬边框）④柔和现代（圆体 + 低对比） |
| 画面密度 | ①每屏一个焦点 ②中等（主图 + 2–3 条标注）③信息密集（仪表盘式） |

### 第二轮 · 动效与声音

| 问题 | 选项 |
|---|---|
| 运动性格 | ①克制精确（短缓动、无回弹）②轻快（小回弹、快切）③电影感（慢推拉、景深）④弹跳（明显 overshoot） |
| 转场方式 | ①形变（同一元素变形）②硬切（按拍点切）③运镜（推/拉/环绕穿过）④文字驱动（字块入场带动画面） |
| 旁白声音 | ①中文男声（沉稳）②中文女声（清晰）③无旁白，只字幕 ④无旁白，只音乐 |
| 配乐气质 | ①极简铺底（低频 + 稀疏）②节奏驱动（120BPM 电子）③管弦（宏大）④无音乐 |

### 第三轮 · 约束（按需，缺什么问什么）

| 问题 | 选项 |
|---|---|
| 时长 | ①45–90 秒预告 ②3 分钟速览 ③5–7 分钟深讲 ④10 分钟以上 |
| 画幅 | ①16:9 横版 ②9:16 竖版 ③1:1 ④横竖各一版 |
| 受众 | ①组会/同行 ②泛技术读者 ③完全外行 ④投资人/客户 |
| 变换强度 | ①克制（每章一次形变）②大胆（每章 2–3 次，含爆炸/拆解/重组）③狂放（每 2–4 秒一次，图形持续变形） |
| 风格扩展 | ①只用参考风格 ②参考为主 + 相容卫星风格（例：机核风 + 示波器 + 等距爆炸图）③大胆混搭（可引入对立风格，但必须有过渡逻辑） |
| 明确不要 | 自由文本（例：不要深色科技风、不要粒子、不要 AI 配音） |

## 输出契约

写入 `output/<project>/0-brief/design-intake.md`：

```markdown
# 设计访谈记录

- 时间：____
- 方式：AskUserQuestion 第 1/2 轮（或：用户未在线，按默认值）

## 选择
| 维度 | 选择 | 备注 |
|---|---|---|
| 视觉语言 | 工程蓝图 | 参考：v3 蓝图版 |
| 主强调色 | 暖橙 | |
| 排版气质 | 紧凑技术感 | |
| 画面密度 | 每屏一个焦点 | |
| 运动性格 | 克制精确 | |
| 转场方式 | 形变 | |
| 旁白 | 中文男声 | edge-tts Yunxi |
| 配乐 | 极简铺底 | numpy 合成 |
| 时长 | 5–7 分钟 | |
| 画幅 | 16:9 | |
| 受众 | 泛技术读者 | |
| 不要 | 深色科技风、粒子爆炸 | |

## 变换强度（必填）

写清"每章至少几次形态变化、有没有章节间的机械转场、哪些图形会互相变形"。
默认按 `大胆`：每章 ≥2 次形变，每 45 秒一次形式转场（光圈/闸门/扫描擦除），
且图形族至少三套（例如：点阵 → 齿轮 → 仪表）。

## 一句话风格内核
> 像一张会动的工程图纸：深蓝方格纸、线框零件、单一橙点标注当前部件，镜头克制。

## 与上一版的差异（重做时必填）
- 保留：逐句字幕、论证结构
- 更换：视觉语言、版面语法
- 新增：残差与层归一化章节
```

## 合并进 brief

`prompt-forge` 读取本文件，把"一句话风格内核"写进 `<style>` 首行，
把"不要"追加到 `<forbidden>`，把时长/画幅写进 `<duration>` 与 `<tech>`。

## 用户不在线时

按项目类型给默认值并标注假设：

| 项目 | 默认风格 |
|---|---|
| 论文讲解 | 工程蓝图 · 克制精确 · 中文男声 · 5–7 分钟 · 16:9 |
| 产品发布 | 极简白或品牌色 · 轻快 · 120BPM · 45–90 秒 |
| 组会分享 | 编辑纸本 · 克制 · 中文男声 · 8–12 分钟 · 16:9 |
| 社交媒体 | 暗场霓虹 · 弹跳 · 竖版 · 30–60 秒 |

## 可视化风格选择器

**权威版本是工作区根目录的 `design-picker.html`**（v2 全维度）；本技能的
`templates/style-picker.html` 是它的同步副本（make-pack.ps1 自检两者一致）。

单文件页面，直接双击打开：

- **8 张风格卡**，每张都有真实动效预览（机械霓虹 NEON ORBIT / 工程蓝图 / 编辑纸本 / 暗场霓虹 /
  极简白 / 粗野主义 / 柔和立体 / 示波终端）；
- **61 个决策维度**，九区：A 项目交付 · B 视觉 · C 动效与特效 · D 运镜与场景切换 ·
  E 标题字幕 · F 声音 · G 受众 · H 结构交付 · I 参考内容；另有 6 条锁定铁律展示；
- 输出三件套：**JSON**（粘贴回对话）· **paperpipe.yaml**（放进运行目录）·
  **design-intake.md**（61 行总表 + 动效运镜计划 + 参考清单，下载进 `0-brief/`）。

用法：把文件路径发给用户，或让用户自己打开后把任一产物交回来。用户在线只走关键
维度（design-intake 本技能的两轮问卷）即可，其余用选择器默认值。

## 反模式

- 一次问 12 个问题（分两轮，每轮 4 题）；
- 问"你喜欢什么颜色"（给四个具体色卡）；
- 用户说"随便"就跳过——按默认值走，并在记录里写明假设；
- 问完不落盘（必须写 `design-intake.md`，否则下一阶段无从引用）。
