# 文字逐字亮起

运行 npm install，再运行 npm run studio 或 npm run render。

画幅 1920×1080；每秒 60 帧；289 帧。

同一绘制实现供目录与独立Remotion组件使用；所有示例由帧号直接求值。源码、字体和许可均在导出的工程内，不需要原始工程或运行时联网。多语文字保留原作的系统字库后备：泰文、阿拉伯文、天城文、希伯来文需要对应系统字体。普通拉丁界面文字使用随包的Oswald；字形造型和诗句纹理保留原字体。

命令行 export.mjs 已复制 binary-assets.json 列出的工程与素材，不需要再次准备。仅从目录复制文字源码时，还需运行 node prepare-assets.mjs <素材包根目录或网址>，再运行 npm run check:source。程序只复制清单里的文件，核对内容摘要并保护已有修改；模型、视频、纹理与原声不会内嵌到文字源码。
